Built-in Verification

Checks run after each calculation

The verification panel checks internal consistency (one Lagna value everywhere, Moon/Nakshatra agreement, Rahu–Ketu opposition, D9 range, house numbering, and engine output). It does not prove a spiritual interpretation; it verifies the software's numerical pipeline.

Location data

Live geocoding • no API key

Place suggestions and coordinates are retrieved live from the public Photon search service backed by OpenStreetMap data. Coverage depends on what is mapped in OpenStreetMap; it is designed for India-wide village, locality, town, city, district, state and address search without a Google API key.

Report note

Professional-use transparency

Swiss Ephemeris is an astronomical calculation engine. Rashi, Nakshatra, D9, Dasha and Manglik are derived using explicit Jyotish rules on top of the ephemeris. Marriage timing and other predictions are interpretive and should not be presented as scientifically certain.
